# Description
This is a multitarget card application written in C++ using the SDL3 library.
The first card application is Solitaire, a Klondike clone using Italian regional cards.

Compilation targets are:
    - Linux (via WSL2 when developed on Windows)
    - Windows (using MSYS2 and CMake)
    - Android (using build.gradle)
    - Wasm (using Emscripten)
